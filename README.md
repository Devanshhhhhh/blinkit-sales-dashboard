# 📊 Blinkit Sales Dashboard

A Power BI dashboard built to analyze 10 years of Blinkit sales data, providing actionable insights through interactive visualizations.

## Features
- Year-wise and category-wise sales trends
- KPI cards for revenue, orders, and growth rate
- Interactive filters by region, category, and time period

## Tech Stack
- Power BI
